# v0.13.4

KGDB smoke-test fixes. No breaking changes.

Merged since v0.13.3: [#638](https://github.com/berntpopp/gene-curator/pull/638).

## Highlights

- **`blocks_submit` on excluded rows.** `GET /curations/{id}/score` (MCP `calculate_score`)
  marks each `breakdown.excluded` entry with `blocks_submit`: true for the reasons submit refuses
  (no PMID, no or placeholder variant, missing `score_status`, unknown PMID). The draft score and
  the submit gate now agree.
- **Stray row columns warn.** A save warns `<row>.<column>: not a column of this table` for a
  row cell that the table's `columns` don't define (for example `variant_type` on KGDB probands).
  It's a warning, never a refusal.
- **`approve_precuration` takes `lock_version`.** It's optional; a stale one returns 409 with the
  usual conflict body, as update and submit do.

## Upgrading

Pull the new images. No migrations.
