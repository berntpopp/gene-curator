# v0.14.7

## Fixed

- **Backend memory (Docker).** The production image hardcoded `--workers 4` (~240 MB each), so
  the backend sat at ~973 MB of its 1 GB limit at ~1% CPU, and no env var could lower it.
  uvicorn now takes its worker count from `WEB_CONCURRENCY`, which the image defaults to `2`.
  Rate-limit buckets are per worker, so the effective rate limit also drops from 4x to 2x the
  configured rate.

## Deploy

`docker/docker-compose.npm.yml` passes `WEB_CONCURRENCY` (default 2) from `.env.docker` and raises
the backend memory limit from 1G to 1536M. Set `WEB_CONCURRENCY` in `.env.docker` to change it.
