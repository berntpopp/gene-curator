# v0.13.3

MCP runtime upgrade: fastmcp 4.1.3 (mcp 2.3). No API or schema changes.

Merged since v0.13.2: [#635](https://github.com/berntpopp/gene-curator/pull/635).

## Highlights

- **fastmcp 4 (#635).** The in-process OpenAPI client is `httpx2`; tool annotations use the
  v4 `ToolAnnotations` names (clients still receive `readOnlyHint` etc.); the audit middleware
  maps `httpx2.HTTPStatusError` to the structured error codes again. Tools, their annotations,
  `/mcp`, `/mcp/full` and the OAuth endpoints are unchanged.
- **Tool titles.** fastmcp 4 gives every tool a display `title` (some clients, ChatGPT among
  them, drop untitled tools), so the `/mcp` tool list grew to about 44 KB.

## Upgrading

Pull the new images. No migrations.
