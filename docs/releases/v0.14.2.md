# v0.14.2

KGDB curations record the kidney clinical group. No code changes; no migrations.

## Highlights

- **`clinical_group` in both KGDB curation schemas** (Mendelian and Susceptibility; not the
  precurations), shown in the Summary tab after *Evidence summary*. Optional, so existing
  curations stay valid. Scoring is unchanged.
  - `primary`: one of `complement`, `cakut`, `glomerulopathy`, `cyst_cilio`, `tubulopathy`,
    `nephrolithiasis`, `neoplasia` (KGDB's HPO clinical groups).
  - `secondary`: a list of the same keys.
  - `rationale`: the sourced kidney phenotype that places the entity in the group, at most 400
    characters. It is a curator judgement, so the LLM second view never sees it; `primary` and
    `secondary` are shared.
- The export (`GET /api/v1/export/curations`) carries it as entered in `evidence.clinical_group`.

## Upgrading

Re-import `docs/schemas/kidney-genetics/kgdb-methodology.json` (`POST /api/v1/schemas/methodologies/import`, `dry_run=true` first,
or the methodology import page). That publishes a new methodology version of both curation
schemas; curations pinned to the previous version keep it until moved to the new one.
