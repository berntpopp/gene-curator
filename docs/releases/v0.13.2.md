# v0.13.2

KGDB curation release: curations cite ClinGen's classification beside our own, and fixes from
the KGDB end-to-end re-curations. Also dependency updates.

Merged since v0.13.1: [#627](https://github.com/berntpopp/gene-curator/pull/627),
[#629](https://github.com/berntpopp/gene-curator/pull/629), #630, #631, #632, #634.

## Highlights

- **ClinGen reference on our own curations (#627).** `clingen_reference` on
  `PUT /api/v1/curations/{id}` (MCP `update_curation`) takes the GeneFoundry
  `clingen_get_gene_validity` record, checked against the curation's gene, MONDO and MOI (422 on
  a mismatch, `null` clears it). Submitting needs a rationale when our class differs from
  ClinGen's. The curation export carries it as a `clingen_reference` statement. A disease
  correction drops the old entity's reference.
- **KGDB re-curation fixes (#629).** A save warns when a missing field zeroes a scored row;
  MCP `get_curation(fields=…)` returns requested null fields as `null`; prose CNVs and repeat
  insertions score as the KGDB owners decided.
- **Dependencies:** uv 0.13.6 (backend image), vite 8.3.5, setup-uv 10.3.2, Python minor/patch
  group.
