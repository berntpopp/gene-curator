# v0.14.1

Security patch for the frontend dev toolchain. No app behaviour changes.

## Fixes

- **minimatch** (GHSA, Dependabot alert #238, moderate): a crafted glob pattern could cause a
  denial of service. Pinned to 11.0.x via an npm `overrides` entry. Only ESLint and
  `@vue/test-utils` use it; the built app never loads it.
- **glob** (GHSA-3g3m-2fjr-6pw4, moderate): a cancelled glob could keep walking the file system.
  Pinned to 14.0.x the same way, also used only by `@vue/test-utils`.

## Not included

TypeScript 7 (#633) waits until typescript-eslint supports it; its current release accepts
TypeScript below 6.1.

## Upgrading

No migrations. Rebuild the frontend image or run `npm ci`.
