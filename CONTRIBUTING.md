# Contributing to Gene Curator

Thanks for helping. Everything you need is in [AGENTS.md](AGENTS.md): setup, commands, architecture,
coding rules and the PR checklist. In short:

1. `make install`, then `make hybrid-up`, `make backend`, `make frontend`.
2. Branch `feature/...` or `fix/...`; commit with [Conventional Commits](https://www.conventionalcommits.org/).
3. Add tests (changed lines need 90% coverage) and run `make ci` before opening a PR.

Questions, bugs and ideas: open an issue using the templates. Contributions are licensed under the
project's [MIT license](LICENSE).
