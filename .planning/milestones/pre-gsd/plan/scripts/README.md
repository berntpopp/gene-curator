# Archived ClinGen training materials

This pre-GSD archive preserves the five converted Markdown documents and their index.
The one-off downloader, its dependency list, and cached PDF/HTML downloads are local,
gitignored reference files; they are not shipped or maintained repository tooling.
Existing local copies, including the SOP v11 PDF, are preserved by the cleanup.

Use the [document index](clingen_documents/INDEX.md) to navigate the archived conversions:

- [Gene-disease validity SOP v11](clingen_documents/markdown/gene_disease_validity_sop_v11.md)
- [Disease naming guidance](clingen_documents/markdown/clingen_disease_naming_guidance.md)
- [Evidence summary template](clingen_documents/markdown/evidence_summary_v5_1.md)
- [Gene-disease association article](clingen_documents/markdown/gimjournal_article.md)
- [Additional training document](clingen_documents/markdown/google_doc.md)

These conversions are historical reference material. Clinical scoring reviews must check the
actual primary-source PDF, including its tables and page-specific examples, rather than rely
on extracted Markdown. The [official SOP v11 PDF](https://www.clinicalgenome.org/site/assets/files/9851/gene-disease_validity_standard_operating_procedures-_version_11_docx.pdf)
is the source recorded by the archived downloader. Raw filenames in the index identify the
local source copies; they are not repository download links.
