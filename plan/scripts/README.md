# Archived ClinGen training materials

This legacy directory preserves five converted Markdown documents and their
[document index](clingen_documents/INDEX.md). The duplicate one-off downloader,
its dependency list and cached PDF/HTML files are local, gitignored references;
they are no longer shipped or maintained repository tools. Existing local copies,
including the SOP v11 PDF, remain intact.

These conversions are historical research material. Clinical scoring reviews must
inspect the actual primary-source PDF, including tables and page-specific examples.
The [official SOP v11 PDF](https://www.clinicalgenome.org/site/assets/files/9851/gene-disease_validity_standard_operating_procedures-_version_11_docx.pdf)
is the source recorded by the archived downloader. Original filenames in the index
identify local copies, not repository download links. Maintained application and
orchestration tooling is unaffected.
