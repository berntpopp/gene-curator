# v0.10.1

Wave 8 follow-up release: a versioned export of reviewed curations, url fields in schemas,
X-linked and Undetermined MOI options, schema-defined verdicts, MONDO susceptibility search and
point-model rows that require a variant.

Every item cites a merged PR, checked against `gh pr view` and the merged code on 2026-10-30
(merged since v0.10.0: #544–#548).

## Highlights

- **Export of reviewed curations (#532).** `GET /api/v1/export/curations` is public; signed-in
  callers also get their member scopes. Each row is an active or archived curation with its id,
  `entity_key`, a link back, HGNC id and symbol, disease, MONDO, MOI with its HPO CURIE, the
  computed verdict and scores, methodology (`schema_name`, `version`, `version_id`), deduplicated
  PMIDs, curator and reviewer names, and approved, activated, archived and updated dates. Paging
  is keyset on (`updated_at`, id) through an opaque `next_cursor`, with an `updated_since` filter
  and at most 500 rows per page. Visibility reuses the existing scope rules (non-members see
  active curations only); no migration, no new RLS. The MCP tools gain
  `export_reviewed_curations`. Contract: [docs/EXPORT.md](../EXPORT.md).
  [#547](https://github.com/berntpopp/gene-curator/pull/547)
- **url fields (#538).** Schemas with `url` fields and `url` evidence-table columns publish.
  Values must be http(s) URLs with a host (checked with `urllib.parse`, not the regex that
  rejected valid paths and queries); table cells are checked too. The form has an open-link
  button; read-only and review views render a link with `rel="noopener noreferrer"`, and only
  for http(s) URLs with a host, never `javascript:` or `data:`.
  [#548](https://github.com/berntpopp/gene-curator/pull/548)
- **MOI options (#531).** Migration 070 publishes a ClinGen Precuration version that adds `XL`
  (X-linked, HP:0001417) and `Undetermined` (HP:0000005). XLD and XLR stay, so stored values do
  not change; the migration skips a working copy that was edited. The LLM second view accepts
  `Undetermined`, and the UI labels XL and SD.
  [#545](https://github.com/berntpopp/gene-curator/pull/545)
- **Schema-defined verdicts and MONDO susceptibility (#539, parts a and b).**
  `GET /schemas/scoring-engines/{engine}?schema_id=` lists the classes that schema's point model
  can emit (bands, then overrides); without `schema_id` it lists the template classes, and an
  unknown schema gets 404. MONDO typed search now also finds disease susceptibility terms
  (for example MONDO:0011037) and still excludes animal diseases.
  [#546](https://github.com/berntpopp/gene-curator/pull/546)
- **require_variant (#535).** A count-based point-model type can set `"require_variant": true`:
  rows with points then need a real variant (`variant` or `variant_1`), without the
  `score_status` rule of SOP v11 case rows. Rows without one score 0 and are listed as
  `no_variant` or `placeholder_variant`; a non-boolean flag is rejected at publish. Models
  without the flag are unchanged. [#544](https://github.com/berntpopp/gene-curator/pull/544)

## Breaking changes

None. The export endpoint and the MCP tool are new; the `schema_id` parameter is optional.

## Upgrading

1. Upgrade through the [v0.10.0 instructions](v0.10.0.md#upgrading) first.
2. Run `make db-migrate` to apply `070_clingen_precuration_moi_xl_undetermined` before
   restarting the backend. [#545](https://github.com/berntpopp/gene-curator/pull/545)

## Known limits

- Anonymous export callers get `methodology.version = null` (methodology versions are readable
  when signed in only); `version_id` is always set. Anonymous callers do not see archived rows.
  [#547](https://github.com/berntpopp/gene-curator/pull/547)
- For members, a soft-deleted curation appears in the export as archived with `archived_at`
  null. [#547](https://github.com/berntpopp/gene-curator/pull/547)
- A required url field holding only spaces passes validation.
  [#548](https://github.com/berntpopp/gene-curator/pull/548)
- #539 stays open: the relationship type (risk, susceptibility) and a schema-defined
  classification vocabulary are not done.
  [#546](https://github.com/berntpopp/gene-curator/pull/546)
- Claude.ai custom connectors over OAuth have not been tested against a public URL.
