# v0.14.5

## Fixed

- **Export page size (#650).** `GET /api/v1/export/curations` with `limit` of 250 or more
  returned a proxy 502 (about 63 KB per item). Pages are now served at most 100 items; a larger
  `limit` is accepted and served as 100, with `next_cursor` for the rest. Clients that page by
  cursor need no change.

## Added (additive; existing calls unchanged)

- **Gene filters on list_precurations (#651).** `GET /api/v1/precurations/` (MCP
  `list_precurations`) takes `gene_symbol` and `hgnc_id`, like `list_curations`, which takes
  `hgnc_id` too. Matching is case-insensitive on the indexed `upper()` columns. An unknown gene
  returns an empty page.
- **Section totals in the save result (#652).** The concise result of `save_draft_curations`,
  `update_curation` and `submit_curation` gains `section_totals` (for example `genetic_total`,
  `experimental_total`, or `genetic_evidence_total` for ClinGen), next to the existing
  `total_score`, `verdict` and `lock_version`.
