# v0.8.0

Wave 6 release: row-level security hardening, scoring with the schema's own engine, review and
navigation fixes, save-state fixes, read-only inactive scopes and security dependency updates.

## Security and access

- A production build no longer contains the seeded development logins: `Login.vue` builds the
  credentials behind a build-time constant, and the tracked `frontend/.env` no longer sets
  `VITE_ENABLE_DEV_LOGIN=true`. A bundle spec builds with the committed `.env` files and checks
  this. [#467](https://github.com/berntpopp/gene-curator/pull/467)
- Migration 050: users outside a scope, anonymous sessions included, see only **active**
  curations of public scopes; scope members still see all their scope's work. This closes a live
  leak: `GET /curations/{id}` returned a draft in a public scope to an outsider (200, now 404).
  050 also hides deactivated public scopes. [#474](https://github.com/berntpopp/gene-curator/pull/474)
- Migration 054: outsiders see a precuration only when an active curation of an active public
  scope was made from it, so `GET /genes/{id}/progress` without `scope_id` no longer counts
  drafts. A restrictive UPDATE policy blocks every update of curations in an inactive scope.
  [#474](https://github.com/berntpopp/gene-curator/pull/474)
- Migration 051: the review archive policy requires an active scope. Only the reviewer who made a
  per-item accept may withdraw or restore it, and only while they still hold reviewer or
  scope-admin rights; others get 403. [#474](https://github.com/berntpopp/gene-curator/pull/474)
- Migration 053: a trigger keeps `publications.added_by` immutable (except the FK's ON DELETE SET
  NULL). [#474](https://github.com/berntpopp/gene-curator/pull/474)
- Async database sessions (publications, logs) now set the RLS user for every transaction.
  [#472](https://github.com/berntpopp/gene-curator/pull/472)
- Paths containing a NUL byte are rejected with 400 and paths over 2048 characters with 414
  before routing. A client `X-Request-ID` matching `[A-Za-z0-9._-]{1,128}` is reused, also on
  500 responses. [#468](https://github.com/berntpopp/gene-curator/pull/468)
- `GET /genes/{id}/summary` and `/summary/full` compute in memory and no longer write
  `gene_summaries`; the admin recompute upsert retries once on a concurrent insert instead of
  returning 500. [#468](https://github.com/berntpopp/gene-curator/pull/468)

- Writes to curations in an inactive scope (create, update, draft, submit, delete, evidence
  add/update/delete, workflow transitions and peer-review submit) return 409 "This scope is
  inactive; its curations are read-only" instead of a 500 (peer review was 403). Edit and Delete
  are hidden there. [#488](https://github.com/berntpopp/gene-curator/pull/488)

## Scoring

- Curation saves, previews, the publish gate and version impact use the engine named in the
  schema's `scoring_configuration.engine` (`engine_for`). GenCC and qualitative curations are now
  scored by their own engine instead of ClinGen. No engine named, or an unknown name, falls back to
  ClinGen (the unknown case logs a warning). The GenCC and qualitative engines accept half-filled
  drafts instead of failing the save with 500. [#472](https://github.com/berntpopp/gene-curator/pull/472)

## Workflow and review

- Precuration approval uses the scope's default workflow pair when it applies; several active pairs
  sharing the precuration schema without an applicable default refuse the approval (400) and
  change nothing. [#475](https://github.com/berntpopp/gene-curator/pull/475)
- The first Submit click after a cell edit now submits (`aria-disabled` instead of `disabled`);
  Ctrl+Enter commits the focused cell first. [#475](https://github.com/berntpopp/gene-curator/pull/475)
- `validate-transition` returns `missing_fields`; the curation form blocks Submit on missing
  disease fields and explains why. [#475](https://github.com/berntpopp/gene-curator/pull/475)
- Precuration detail shows its status, and a scope reviewer or admin who is not the author can
  approve or request changes there. "New assignment" shows only to scope and app admins; viewers
  and reviewers get no Save draft on `curation/new`; the Review nav item no longer disappears; My
  work Done counts the reviewer's own approvals. [#473](https://github.com/berntpopp/gene-curator/pull/473)
- A non-member can open a public scope's dashboard; intake counts deduplicate repeated entries.
  The workflow schema picker shows name, version and (for duplicates) creation date, in a stable
  order. Cards and dialogs follow the design rules, and deleting an active curation names the
  impact. [#473](https://github.com/berntpopp/gene-curator/pull/473)
- `GET /scopes/` also lists active public scopes for non-members (`user_role: null`), so the
  Scopes page is no longer empty for them. On a public scope's dashboard an outsider gets no
  statistics or members calls and no Genes tab, which wrongly said "no genes".
  [#488](https://github.com/berntpopp/gene-curator/pull/488)
- Opening `/edit` for an active curation redirects to the read-only detail view, so a viewer's
  link no longer lands on dead Save/Submit buttons. [#488](https://github.com/berntpopp/gene-curator/pull/488)
- A re-curation's first review diffs against the active curation it replaces. "Changes requested"
  on a precuration shows the reviewer and date. [#476](https://github.com/berntpopp/gene-curator/pull/476)
- Scope and assignment statistics count In review / In progress correctly (they were always 0);
  not-found curation and precuration pages show a clear message; expired tokens with base64url
  payloads are detected before `/auth/me`. [#476](https://github.com/berntpopp/gene-curator/pull/476)
- Text typed in an evidence cell marks the form unsaved after 400 ms (and on unmount), so it is
  kept as a local draft and guarded on leave. A new curation or re-curation prefill shows Unsaved
  changes until its first save. [#477](https://github.com/berntpopp/gene-curator/pull/477)

## Performance and cleanup

- Migration 052 adds case-insensitive btree and GIN indexes for gene symbol, HGNC ID, previous and
  alias symbols; gene resolve pre-filters on them on PostgreSQL. Matching is unchanged.
  [#474](https://github.com/berntpopp/gene-curator/pull/474)
- Shutdown waits up to 5 s for pending DB-logger writes and always disposes the async engine.
  [#472](https://github.com/berntpopp/gene-curator/pull/472)

## Seed data

- The demo scope memberships in `004_seed_data.sql` are seeded as accepted (`accepted_at` set), so
  they no longer act as pending invitations that grant nothing. Migration 055 backfills existing
  databases for the four seeded demo users only. [#488](https://github.com/berntpopp/gene-curator/pull/488)

## Upgrading

1. Upgrade older installations through the [v0.7.0 instructions](v0.7.0.md#upgrading) first.
2. Run `make db-migrate` to apply 050–055 before restarting the backend.
   [#474](https://github.com/berntpopp/gene-curator/pull/474),
   [#488](https://github.com/berntpopp/gene-curator/pull/488)
3. Users outside a scope now get 404 for drafts and other non-active curations and precurations in
   public scopes, and no longer see deactivated public scopes. Members are unaffected.
   [#474](https://github.com/berntpopp/gene-curator/pull/474)
4. Scoring behaviour change: saving a curation pinned to a GenCC or qualitative schema now scores
   it with that engine, so its stored verdict can change on the next save. `make recompute-scores`
   stays ClinGen-only and skips these curations. [#472](https://github.com/berntpopp/gene-curator/pull/472)
5. Production builds need no dev-login setting; keep `VITE_ENABLE_DEV_LOGIN=true` only in
   `frontend/.env.local` for local development. [#467](https://github.com/berntpopp/gene-curator/pull/467)

## Known limits

- Follow-ups from Wave 6 reviews, tracked in [#478](https://github.com/berntpopp/gene-curator/issues/478):
  the 400/414 path rejects carry no CORS headers; the `gene_summaries` table is now write-only;
  configured rate limits are not enforced; recompute is ClinGen-only; the gene `hgnc_id` repoint is
  not yet admin-only. [#468](https://github.com/berntpopp/gene-curator/pull/468),
  [#472](https://github.com/berntpopp/gene-curator/pull/472),
  [#474](https://github.com/berntpopp/gene-curator/pull/474)
- Legacy disease gaps: the form now explains them, but there is no in-app correction path yet
  ([#453](https://github.com/berntpopp/gene-curator/issues/453), partial in
  [#475](https://github.com/berntpopp/gene-curator/pull/475)).
- Family/method-aware segregation scoring is still open
  ([#447](https://github.com/berntpopp/gene-curator/issues/447)).
- An outsider's role lookup on a public scope's dashboard still calls `/members` once and gets 403,
  and the Genes tab is hidden for outsiders rather than listing genes with active curations
  ([#484](https://github.com/berntpopp/gene-curator/issues/484) remainder, noted in
  [#488](https://github.com/berntpopp/gene-curator/pull/488)).
