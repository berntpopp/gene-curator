# v0.14.4

## Fixed

- Adding a mitochondrial gene (for example MT-TF, HGNC:7481) to a scope returned HTTP 500.
  HGNC gives such genes the location "mitochondria", which was stored whole as the chromosome
  and overflowed its 10-character column. The chromosome is now parsed as `MT` for
  mitochondrial genes, and as empty for non-loci such as "unplaced" or "reserved".
- One HGNC record that does not fit the gene table now marks only that gene as unverified
  (`not_found`) instead of failing the whole `add_genes_to_scope` call.

## Dependencies

- Backend lock: Python minor/patch updates (#647).
