# v0.14.3

KGDB Susceptibility Curation: functional evidence rows take a verbatim quote. No code
changes; no migrations.

## Fixes

- **`experimental.functional[].evidence_quote`** in the KGDB Susceptibility Curation schema
  (textarea, `llm_share`), after `pmid`, as in the Mendelian schema and the susceptibility
  association table. KGDB requires a verbatim quote (40 words or fewer) on every scored row;
  the functional table had nowhere to put it. Optional; scoring unchanged. A new test checks
  that every scored table in both KGDB curation schemas has the column.

## Upgrading

Re-import `docs/schemas/kidney-genetics/kgdb-methodology.json`
(`POST /api/v1/schemas/methodologies/import`, `dry_run=true` first). That publishes a new
methodology version of KGDB Susceptibility Curation only; existing curations keep theirs.
